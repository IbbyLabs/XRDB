# Contributors

People who have given something to XRDB beyond a bug report.

## Translations

Genre label languages live in `internal/compose/labels/`. To add one, copy
`en.json`, translate the labels, and name the file for the language code. A file
need not be complete — a family it does not name keeps its English label.
